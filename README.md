# AI Spend Audit

AI Spend Audit is a web platform that helps startups and engineering teams analyze their AI tool subscriptions, identify overspending, and discover cheaper alternatives or optimized plans.

Built as part of the Credex Web Development Internship Assignment.

---

## Features

- AI tool spend analysis
- Personalized savings recommendations
- AI-generated audit summaries
- Shareable audit reports
- Lead capture and backend storage
- Responsive modern UI

---

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- shadcn/ui
- Supabase
- OpenAI / Anthropic API
